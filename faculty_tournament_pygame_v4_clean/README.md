«Турнир Факультетов» 

Великий Лабиринт открыт. Три ученика — три факультета — три пути к Кубку Школы. Ты можешь сражаться. Можешь торговать. Можешь проклинать. Но помни: лабиринт непредсказуем, а соперники — коварны. Первый, кто дойдёт до центра, — победит. А если твои соперники сойдут с дистанции раньше — Кубок твой по праву. Главное — не потерять себя по пути.
